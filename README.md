# Trabalho-de-Programação-Web
Uma farmácia on-line completa, com experiência de compra comparável a um app comercial (tipo iFood/Drogaria), operação administrativa real (estoque, validade, promoções, relatórios), fluxo de receita médica controlada e gestão de entregas — tudo dentro do escopo de uma aplicação web (a "entrega física" é simulada por telas e mudança de status).
