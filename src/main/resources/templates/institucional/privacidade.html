Política de Privacidade

Versão 1.0. Este é um texto demonstrativo de um projeto acadêmico, não é uma política de produção nem substitui orientação jurídica.

Dados usados na demonstração

Para experimentar os fluxos, a aplicação pode armazenar os dados informados no cadastro, como nome, CPF, data de nascimento, gênero, e-mail e celular; endereços cadastrados; e informações de carrinho e pedidos. Senhas são armazenadas em formato protegido, não como texto legível.

Não informe dados reais, dados de pagamento verdadeiros ou informações de saúde identificáveis. Os dados podem permanecer no banco local do ambiente acadêmico até sua limpeza ou reinicialização.

Finalidades

Esses dados são usados para demonstrar cadastro e confirmação de conta, manutenção de endereços, carrinho, pedidos e controles de acesso. Não são usados para uma venda real ou para aconselhamento médico.

Serviços externos e demonstração

Algumas interações do ambiente são simuladas. Mensagens e pagamentos de demonstração não são enviados nem cobrados como serviços reais. A página de boas práticas explica o contexto acadêmico do projeto.

Privacidade e direitos

Esta página descreve o comportamento demonstrativo da aplicação; ela não oferece um canal automatizado de atendimento ou de solicitação de direitos. Para este trabalho, não cadastre informações pessoais reais.

A versão atual desta Política de Privacidade é 1.0, a mesma informada no aceite do cadastro.
